## Credentials

Create an API key in Google AI Studio. SAGU reads `GEMINI_API_KEY`, then `GOOGLE_API_KEY`, or the `apiKey` option, which takes precedence.

```bash
export GEMINI_API_KEY="your-key-here"
```

## Usage

```ts
import { Agent, gemini } from "sagu-sdk";

const agent = new Agent({
  name: "Assistant",
  instructions: "Be concise.",
  model: gemini({ model: "your-model-id" }),
});
```

## Request mapping

- `systemPrompt` → `systemInstruction`. Assistant messages → role `model`. Tool calls → `functionCall` parts; tool results → `functionResponse` parts.
- `tools` → `[{ functionDeclarations: [...] }]`.
- `temperature` / `maxTokens` → `generationConfig`.
- `name` of the provider is `gemini:<model>`.

## Limitations

- **The API key is in the URL.** Make sure proxies or custom `fetch` wrappers don't log full URLs.
- **`outputSchema`** is not sent natively; it relies on the prompt plus validation.
- **`stream()` is not incremental.**
- **The default model ID is old** and may be retired. Pass `model`.
