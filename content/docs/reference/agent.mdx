## `class Agent<TOutput = string>`

```ts
new Agent<TOutput>(config: AgentConfig<TOutput>)
agent.run(input: string, options?: RunOptions): Promise<RunResult<TOutput>>
agent.stream(input: string, options?: RunOptions): AsyncGenerator<AgentEvent<TOutput>, void, unknown>
```

The constructor throws `ConfigurationError` if `name` is empty, `instructions` is falsy, or `model` has no `generate` function. All config is copied into `readonly` fields, and the `tools`, `handoffs` and guardrail arrays are frozen.

`maxTurns`, `maxHandoffs` and `maxRepairAttempts` are read from the agent that **starts** the run. Handoff targets' values are ignored.

### `RunContext`

Passed to function `instructions`:

```ts
interface RunContext {
  runId: string;
  agentName: string;
  sessionId?: string;
  turn: number;
}
```

## `RunResult<TOutput>`

```ts
type RunResult<TOutput = string> =
  | { success: true;  output: TOutput;  messages: Message[]; usage: TokenUsage; agentName: string; turns: number; trace?: Trace }
  | { success: false; error: SaguError; messages: Message[]; usage: TokenUsage; agentName: string; turns: number; trace?: Trace };
```

## Functions

```ts
function runAgent<TOutput = string>(agent: Agent<TOutput>, input: string, options?: RunOptions): Promise<RunResult<TOutput>>;
function streamAgent<TOutput = string>(agent: Agent<TOutput>, input: string, options?: RunOptions): AsyncGenerator<AgentEvent<TOutput>, void, unknown>;
```

`agent.run` and `agent.stream` delegate to these. `runAgent` throws a `SaguError` only if the stream ends without a terminal event, which should not happen.
