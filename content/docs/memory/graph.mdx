Both stores implement:

```ts
interface GraphMemoryStore {
  remember(entry: GraphMemoryEntry): Promise<void>;     // upsert
  recall(query: { about: string; limit?: number }): Promise<GraphMemoryEntry[]>;
  listFacts(): Promise<GraphMemoryEntry[]>;
  forget(key: { subject: string; predicate: string; object: string }): Promise<void>;
  mergeEntities(from: string, into: string): Promise<void>;
  close(): Promise<void>;
}

interface GraphMemoryEntry {
  subject: string; predicate: string; object: string;
  confidence?: number;   // 0..1, default 1
  mentions?: number;     // maintained by the store
  source?: string;       // "session:<id>", "tool:remember_fact", "inferred:<rule>", …
  createdAt?: number;    // epoch ms, preserved on upsert
  updatedAt?: number;    // epoch ms, refreshed on upsert unless given
  metadata?: Record<string, unknown>;
}
```

Facts get written by the [background processes](/docs/features/background-processes) when you use `LongTermMemory`, by the `remember_fact` tool, or by your own `store.remember()` calls.

## InMemoryGraphMemoryStore

```ts
import { InMemoryGraphMemoryStore } from "sagu-sdk";

const store = new InMemoryGraphMemoryStore();
await store.remember({ subject: "User", predicate: "PREFERS_LANGUAGE", object: "TypeScript" });
await store.recall({ about: "language" }); // matches by word
store.allEntries;                          // copy of every triplet
```

- **Lifetime:** process memory only. **Facts do not survive a restart.**
- **Identity:** subject, predicate and object compared case-insensitively. Re-remembering a fact increments `mentions`, keeps `createdAt` and overwrites provided fields.
- **Recall:** case-insensitive; matches if the full `about` text is in `"subject predicate object"`, or **any word** of `about` is in any part. Returns at most `limit` (default 10). An empty `about` returns the first `limit` facts.
- **`mergeEntities(from, into)`** renames the exact name `from`; facts that become identical are combined (max confidence, summed mentions), and facts that become self-loops are dropped.

## Neo4jGraphMemoryStore

### 1. Run Neo4j

For local development, Neo4j's official Docker image works:

```bash
docker run --rm -p 7474:7474 -p 7687:7687 -e NEO4J_AUTH=neo4j/your-password neo4j:5
```

### 2. Install the driver

```bash
npm install neo4j-driver   # optional dependency of SAGU
```

### 3. Configure

```bash
export NEO4J_URI="bolt://localhost:7687"
export NEO4J_USER="neo4j"
export NEO4J_PASSWORD="your-password"
```

```ts
import { Neo4jGraphMemoryStore, createAutoGraphMemoryStore, createGraphMemoryTools } from "sagu-sdk";

// Explicit
const store = new Neo4jGraphMemoryStore({ uri: process.env.NEO4J_URI!, database: "neo4j" });

// Or: Neo4j if NEO4J_URI is set, otherwise in-memory
const auto = await createAutoGraphMemoryStore();

const tools = createGraphMemoryTools(store);
// …
await store.close();
```

### Data model

```cypher
// remember(): upsert
MERGE (s:Entity { name: $subject })
MERGE (o:Entity { name: $object })
MERGE (s)-[r:RELATION { type: $predicate }]->(o)
ON CREATE SET r.createdAt = coalesce($createdAt, timestamp()), r.mentions = 0
SET r.mentions = r.mentions + 1,
    r.confidence = coalesce($confidence, r.confidence, 1.0),
    r.source = coalesce($source, r.source),
    r.updatedAt = coalesce($updatedAt, timestamp())

// recall(): any term matches, highest confidence first
MATCH (s:Entity)-[r:RELATION]->(o:Entity)
WHERE size($terms) = 0 OR any(t IN $terms WHERE
  toLower(s.name) CONTAINS t OR toLower(o.name) CONTAINS t OR toLower(r.type) CONTAINS t)
RETURN s.name AS subject, r.type AS predicate, o.name AS object, r.confidence AS confidence, …
ORDER BY coalesce(r.confidence, 1.0) DESC
LIMIT toInteger($limit)
```

- Every node is an `:Entity` with a `name`; every edge is a `:RELATION` with a `type` property, not a native relationship type.
- `MERGE` prevents exact duplicates. Entity names are **case-sensitive** here; the [maintainer](/docs/features/background-processes#3--graphmaintainer) merges case and spelling variants.
- `forget` deletes the relationship, then any entity left without relationships.
- `mergeEntities` moves each fact to the new name (combining with existing ones), then deletes the old node. It runs as several statements, not one transaction.
- `metadata` is not persisted.
