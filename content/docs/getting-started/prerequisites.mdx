## Node.js

| You want to | Minimum Node.js |
|---|---|
| Use the `sagu-sdk` package | **22.13** (declared in `engines`; earlier versions can't load `node:sqlite`) |
| Run `.ts` files directly, like the snippets in these docs | 22.18 / 23.6 (native type stripping), or use `tsx` |
| Run the repository's tests and examples | same as above; verified on **25.8** |

The package was verified by installing it from npm and running it on Node.js 22.13 and 25.8.

Check your version:

```bash
node --version
```

If you use a version manager:

```bash
nvm install 25
nvm use 25
```

## Other tools

- **git**, only if you want to run the examples or contribute.
- **npm** (bundled with Node.js) 7 or newer, so the Zod peer dependency installs automatically.
- **Optional:** a running **Neo4j** instance, only if you want persistent graph memory. See [Neo4j graph memory](/docs/memory/graph#neo4jgraphmemorystore).
- **Optional:** an API key for **Anthropic**, **OpenAI** or **Google Gemini**, only if you want to call a real model. Every example runs without one.

## Knowledge assumed

You should be comfortable with TypeScript, `async`/`await` and ES modules. You do not need any prior experience with LLM agents; [Learn the fundamentals](/docs/learn) covers the concepts.
