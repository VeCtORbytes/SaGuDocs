This builds the smallest complete agent: one tool, one scripted model, one run. It works offline, so you can see the whole loop before you add credentials.

<Callout>Complete [Installation](/docs/getting-started/installation) first: a project with `"type": "module"` and `sagu-sdk` + `zod@3` installed.</Callout>

<Steps>
<Step>

### Create a file

```bash
touch hello.ts
```

</Step>
<Step>

### Write the agent

```ts title="hello.ts"
import { z } from "zod";
import { Agent, defineTool, mock } from "sagu-sdk";

// 1. A tool: name, description, Zod input schema, execute function.
const getTime = defineTool({
  name: "get_time",
  description: "Return the current time for an IANA time zone.",
  input: z.object({ timeZone: z.string().describe("e.g. Europe/Paris") }),
  execute: async ({ timeZone }) => ({
    timeZone,
    time: new Date().toLocaleTimeString("en-US", { timeZone }),
  }),
});

// 2. A model. mock() replays scripted turns, so this runs offline with no API key.
const model = mock([
  { toolCalls: [{ id: "call_1", name: "get_time", arguments: { timeZone: "Europe/Paris" } }] },
  "I looked it up with the get_time tool.",
]);

// 3. An agent: instructions + model + tools.
const agent = new Agent({
  name: "Clock",
  instructions: "Answer time questions using the get_time tool.",
  model,
  tools: [getTime],
});

// 4. Run it. run() returns a result object instead of throwing on expected failures.
const result = await agent.run("What time is it in Paris?");

if (result.success) {
  console.log("output:", result.output);
  console.log("turns:", result.turns);
  const toolMessage = result.messages.find((m) => m.role === "tool");
  console.log("tool result:", toolMessage?.toolResult?.result);
} else {
  console.error(result.error.code, result.error.message);
}
```

</Step>
<Step>

### Run it

```bash
node hello.ts
```

This needs Node.js 22.18+ / 23.6+ to run `.ts` directly. On older versions, use `npx tsx hello.ts`.

```text title="Output (time will differ)"
output: I looked it up with the get_time tool.
turns: 2
tool result: { timeZone: 'Europe/Paris', time: '11:35:45 AM' }
```

</Step>
</Steps>

## What just happened

1. **Turn 1.** The runner sent your instructions, the user message and the `get_time` tool spec to the model. The scripted model replied with a tool call.
2. The runner **validated** `{ timeZone: "Europe/Paris" }` against the Zod schema, **executed** your function, and appended the result to the conversation as a `tool` message.
3. **Turn 2.** The runner called the model again with the tool result. The model returned plain text, so the loop ended.
4. `run()` returned `{ success: true, output, turns: 2, messages, usage, trace, agentName }`.

The scripted model doesn't read the tool result. It just replays its second turn. With a real model, the final sentence would use the actual time. That's the next step.
