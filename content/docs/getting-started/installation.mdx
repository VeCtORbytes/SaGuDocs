<Steps>
<Step>

### Create a project (or use an existing one)

```bash
mkdir my-agent && cd my-agent
npm init -y
npm pkg set type=module
```

SAGU is an ES module package; `"type": "module"` lets you use `import` and top-level `await` in `.js` and `.ts` files.

</Step>
<Step>

### Install

```bash
npm install sagu-sdk zod@3
```

[sagu-sdk on npm](https://www.npmjs.com/package/sagu-sdk). It includes TypeScript types; no `@types` package is needed.

</Step>
<Step>

### Check it loads

```bash
node -e "import('sagu-sdk').then(m => console.log('SAGU ready:', typeof m.Agent))"
# SAGU ready: function
```

</Step>
</Steps>

## Why `zod@3`

You write tool and output schemas with Zod, so Zod is a **peer dependency**: your project and SAGU share one copy. SAGU reads Zod 3 internals to build the JSON Schema it sends to models.

- `npm install sagu-sdk` on its own installs Zod 3 automatically (npm 7+).
- If your project already uses **Zod 4**, npm stops with `ERESOLVE … peer zod@"^3"`. Use Zod 3 in this project.
- Passing a Zod 4 schema anyway throws `ConfigurationError: … requires Zod 3. Install it with: npm install zod@3`.

## Optional: Neo4j driver

`neo4j-driver` is an **optional** dependency, loaded only when a `Neo4jGraphMemoryStore` first connects. If it's missing, that store fails with a `MemoryError` telling you to install it:

```bash
npm install neo4j-driver
```

## Running TypeScript

The package is compiled JavaScript, so it works with any setup: `tsc`, `tsx`, a bundler, or Node.js running `.ts` files directly (Node.js 22.18+ / 23.6+). The snippets in these docs are TypeScript files run with `node file.ts`.

For `tsconfig.json`, `"module": "NodeNext"` and `"moduleResolution": "NodeNext"` match the package. Consumer typechecking was verified with TypeScript 5.0, 5.4 and 5.9.

## Working from source

To run the bundled examples or contribute, clone the repository instead:

```bash
git clone https://github.com/VeCtORbytes/SaGuSDK.git
cd SaGuSDK
npm install
npm test          # 89 tests via node --test (1 skipped without Neo4j), no network or API keys
```

The examples import from `../../src/index.ts`, so they run directly from the clone. See [Run the examples](/docs/getting-started/run-examples).
