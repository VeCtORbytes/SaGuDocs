title: Run the examples
description: Run the five bundled examples. They work offline with the scripted mock model.
---

All five examples live in <Source path="examples" /> and use `mock()`, so they need no API keys or network. They import the SDK from source, so run them from a clone of the repository:

```bash
git clone https://github.com/VeCtORbytes/SaGuSDK.git && cd SaGuSDK && npm install
```

Then:

```bash
node examples/01-basic-tool-agent/index.ts
node examples/02-support-triage-handoff/index.ts
node examples/03-structured-output-and-memory/index.ts
node examples/04-graph-memory-longterm-recall/index.ts
node examples/05-background-graph-memory/index.ts
```

| Example | Shows | Walkthrough |
|---|---|---|
| `01-basic-tool-agent` | `defineTool`, `Agent`, `ConsoleExporter` trace, token usage | [Basic tool agent](/docs/examples/basic-tool-agent) |
| `02-support-triage-handoff` | Handoffs between three agents, `agent.stream()` events | [Support triage handoff](/docs/examples/support-triage-handoff) |
| `03-structured-output-and-memory` | `Agent<LeadProfile>`, schema repair, `SqliteSession` across two runs | [Structured output & memory](/docs/examples/structured-output-and-memory) |
| `04-graph-memory-longterm-recall` | `createGraphMemoryTools`, `InMemoryGraphMemoryStore`, recall from a fresh agent | [Graph memory recall](/docs/examples/graph-memory-longterm-recall) |
| `05-background-graph-memory` | `LongTermMemory`, the three background processes, context injection | [Background graph memory](/docs/examples/background-graph-memory) |

## Running an example against a real model

The examples script their model turns with `mock([...])`. To try one in your own project, copy it, change the import to `"sagu-sdk"`, and replace `mock([...])` with `anthropic()`, `openai()` or `gemini()`. Real models choose their own tool calls, so output varies.
