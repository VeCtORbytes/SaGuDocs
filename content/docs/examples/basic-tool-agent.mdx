## What it demonstrates

1. Defining type-safe tools with Zod schemas (`calculate`, `get_weather`)
2. Creating an `Agent` with tools and a model provider
3. Running with the deterministic `MockProvider`
4. Inspecting output, turns, token usage, message count and a `ConsoleExporter` trace

## Key code

```ts
const calculateTool = defineTool({
  name: "calculate",
  description: "Evaluate a mathematical expression and return the numeric result.",
  input: z.object({
    expression: z.string().describe("Mathematical expression to evaluate (e.g., '14 * 3')"),
  }),
  execute: async ({ expression }) => {
    const sanitized = expression.replace(/[^0-9+\-*/().]/g, "");
    try {
      const result = Function(`'use strict'; return (${sanitized})`)();
      return { expression, result: Number(result) };
    } catch {
      return { expression, error: "Invalid math expression" };
    }
  },
});

const model = mock([
  { toolCalls: [{ id: "call_calc_1", name: "calculate", arguments: { expression: "125 * 8" } }] },
  "125 multiplied by 8 equals 1,000.",
]);

const agent = new Agent({
  name: "MathAndWeatherAssistant",
  instructions: "You are a helpful assistant. Use the calculate tool for math questions and get_weather for weather queries.",
  model,
  tools: [calculateTool, weatherTool],
});

const result = await agent.run("What is 125 * 8?", { traceExporter: new ConsoleExporter() });
```

## Walkthrough

- **Turn 1:** the mock returns a `calculate` tool call. The runner validates `{ expression: "125 * 8" }`, runs the tool, and appends `{ expression, result: 1000 }`.
- **Turn 2:** the mock returns the final sentence.
- `result.messages.length` is **4**: user, assistant (tool call), tool, assistant.
- The trace shows `agent_run` → `model_call`, `tool_execution`, `model_call`.

<Callout type="warn" title="About the calculator">
  The example strips everything except digits and `+-*/().` and then evaluates with `Function(...)`. That's fine for a
  demo, but don't copy dynamic evaluation of model-supplied input into production. Use a real expression parser.
</Callout>

## Try changing

- Swap `mock([...])` for `anthropic()` and ask about the weather: the real model will choose `get_weather`.
- Add `timeoutMs: 1` to a tool whose `execute` awaits a delay to see a timeout error result.
