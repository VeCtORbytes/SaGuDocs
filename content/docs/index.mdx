**SAGU** is an open-source TypeScript SDK for building AI agents: programs where a language model decides which of your functions ("tools") to call, the SDK runs them, and the model uses the results to answer. It is written from scratch, with no agent framework underneath, and its one required runtime dependency is [Zod](https://zod.dev).

The core loop lives in a single file, <Source path="src/runner.ts" />, so you can read exactly what happens on every turn.

<ArchitectureOverview />

## What SAGU is

- **A library you import into your own Node.js code.** You construct an `Agent`, call `agent.run()` or iterate `agent.stream()`, and get back a typed result.
- **Provider-neutral.** Agents talk to a small `ModelProvider` interface. The repository ships adapters for Anthropic, OpenAI and Gemini, a scriptable `MockProvider` for tests, and a `FallbackProvider` that chains them.
- **Predictable.** Expected runtime failures (a guardrail block, `maxTurns` reached, schema repair exhausted, a provider error) come back as `{ success: false, error }` instead of being thrown.

## What SAGU is not

- **Not a hosted model or API.** SAGU does not give you model access. You bring your own API key from Anthropic, OpenAI or Google.
- **Not a chatbot UI.** There is no end-user interface; you build the surface (CLI, HTTP route, worker) yourself.
- **Install:** `npm install sagu-sdk zod@3`, on Node.js 22.13 or newer. See [Installation](/docs/getting-started/installation).
