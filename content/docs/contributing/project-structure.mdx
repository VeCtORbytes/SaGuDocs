## Layers

| Layer | Lifetime | Code |
|---|---|---|
| **Agent configuration** | Immutable after `new Agent()` | `agent.ts`, `types.ts` (`AgentConfig`) |
| **Run state** | One `run()`/`stream()` call | Local variables in `streamAgent()`: messages, turn, handoffCount, usage, trace |
| **Session state** | Across runs, per `sessionId` | `memory/` session stores |
| **Long-term memory** | Across sessions and agents | `memory/` graph stores, accessed via tools |

## Dependencies

| Package | Kind | Why |
|---|---|---|
| `zod` | dependency | Schemas for tools and structured output |
| `neo4j-driver` | optional | Only for `Neo4jGraphMemoryStore` (dynamic import) |
| `typescript`, `@types/node` | dev | Typechecking |

Everything else uses Node.js built-ins: `fetch`, `node:crypto`, `node:fs`, `node:sqlite`, `node:test`.
