title: Known limitations
description: What SAGU does not do yet, gathered in one place.

This list was compiled from the source code at the time these docs were written. Each item links to more context.

## Distribution and runtime

- **Not on npm.** `sagu-sdk` returns 404 on the registry. ([Installation](/docs/getting-started/installation))
- **`npm run build` emits nothing.** `tsconfig.json` has `noEmit: true`, so `dist/` (the `main`/`types` target) is never created. Source files also import with `.ts` extensions, which a publishable build would need to rewrite.
- **Node.js version is undeclared.** There is no `engines` field. Verified on Node.js 25.8 only. ([Prerequisites](/docs/getting-started/prerequisites))
- **Zod 3 only** for JSON Schema conversion. ([Tools](/docs/features/tools#limitations-and-common-mistakes))

## Providers

- Real adapters' `stream()` returns the full text in **one chunk**. ([Streaming](/docs/features/streaming#limitations))
- **No automatic retry** for built-in providers, because the runner only retries providers without `stream()`. ([Reliability](/docs/features/reliability#automatic-retries-in-the-runner))
- **Default model IDs are dated**; pass `model`. ([Configure a provider](/docs/getting-started/configure-provider#pick-a-model-id-explicitly))
- Anthropic `max_tokens` is effectively fixed at 2048. ([Anthropic](/docs/providers/anthropic))
- OpenAI strict JSON schema may reject SAGU-generated schemas. ([OpenAI](/docs/providers/openai))
- Adapters have been tested against stubbed `fetch`, not live APIs.

## Memory

- **Background processes are single-node.** The extraction queue is in memory (lost on crash), there's no lock between two Node processes sharing one Neo4j, and Neo4j merges aren't transactional. ([Background processes](/docs/features/background-processes#limitations))
- **Keyword retrieval, not semantic.** Synonyms aren't matched, and duplicates by meaning (`PREFERS` vs `LIKES`) aren't merged. ([Graph memory](/docs/features/graph-memory#limitations))
- In-memory graph facts **do not persist** across restarts.
- Neo4j doesn't persist `metadata`.
- Sessions are saved only on success; no summarization or token-aware truncation. ([Session memory](/docs/features/session-memory#limitations-and-common-mistakes))
- `FileSession` has no locking for concurrent writers.

## Runtime

- Tool calls in one response run sequentially.
- Output guardrail `modified` text doesn't affect parsed structured output. ([Guardrails](/docs/features/guardrails#limitations-and-common-mistakes))
- Aborted runs use code `SAGU_CONFIG_ERROR`; unknown exceptions are labelled `SAGU_PROVIDER_ERROR`. ([Error handling](/docs/features/error-handling#limitations-and-common-mistakes))
- Traces are SAGU-specific (not OpenTelemetry), have no spans for retries, fallbacks or approvals, and don't record tool arguments. ([Tracing](/docs/features/tracing#limitations))
